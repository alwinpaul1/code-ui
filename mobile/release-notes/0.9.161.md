### Improvements
- A terminal opened under the chat stays covered until its own first frame, so showing the terminal no longer flashes a blank pane or the desktop-width screen
- The log now times each step of opening a session (screen, connection, tab list, terminals and the chat's first read), so a slow open names the step that took the time

### Security & Bug Fixes
- The terminal's 2.5 s fallback no longer runs out behind the chat on every open, and a fallback already running stops when the chat covers the terminal
