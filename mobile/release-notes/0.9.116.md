### Features
- The model and effort show for every Claude tab: tabs started from the phone or Orca update the moment you switch model mid-session, and tabs where you typed `claude` yourself read them from Claude's startup screen
- The model and effort stay right after you switch project or close the app

### Improvements
- Brings in Orca 1.4.221's mobile changes: feeds, timers, file previews and pictures are released when you leave them, and terminal catch-up and encrypted messages use less memory
- A session's own `/model`, `/effort` and `/fast` answers update the pill when nothing else can

### Security & Bug Fixes
- A long message sent from a phone-width tab is confirmed as sent instead of showing "Delivery unconfirmed"
- Closing a file tab, a structured chat or a session tab list no longer leaves it running on the desktop, and a reconnect no longer closes the wrong feed
- A file reopened after a slow read no longer shows an older copy
