### Features
- Messages are never lost: a message is saved the moment you tap send, shows as "Sending…" at once, and is sent when you next open that chat if the app was closed mid-send; a message that can't go shows "Not sent · Retry · Edit"
- The Background tasks sheet looks like the Claude app: a stop button on each running task, Stop all, each agent's latest step, the shells inside subagents as their own rows, token counts, and "Status unknown" while the connection is down
- A redesigned update screen: the new version as the headline, notes grouped by Features, Improvements and Fixes, and a download progress card on Home
- Codex chats offer a Standard, Fast or Ultrafast speed choice, and question cards can take a typed answer
- A /clear shows a "Context cleared" divider and keeps the same chat, and single-choice questions move on as soon as you pick an option

### Improvements
- The + sheet and every other bottom sheet slide up smoothly instead of pausing and jumping
- After Lock or Mute, the PC's menu shows the next buttons straight away instead of "Checking the PC…"
- Desktop agents always report their model and context; the switch for it is gone
- Notifications show the Code UI icon on the lock screen and Always On Display
- Each send's timings are written to Settings → Connection log, so a slow send shows which step took the time
- A new pairing scan is no longer blocked by an interrupted one, and Stage All stages every change past 1,000 files
- Each agent's sign-in instructions name its own login command, and links inside chat visuals switch sections

### Security & Bug Fixes
- Sleep display and Wake display are removed from Windows PCs, because turning the screen off put some laptops to sleep; Lock PC and Mute stay
- "The agent is still working" now says plainly when /clear or /compact is sent while the agent works
- An opened tool line stays with its own command when the chat refreshes
