### Features
- Charts and diagrams the agent attaches to a reply draw inline in the chat, in your light or dark theme, with a full-screen view (needs an Orca desktop with this feature; older ones say Visualization unavailable)
- When an agent starts several subagents, the chat shows one live row for the group with its status, time and tokens, and opens to a line per subagent
- Video and music files play on the phone, from the file browser or a path tapped in the chat (needs an Orca desktop that allows media previews)

### Improvements
- Big images send faster, closed Markdown files free their memory, typing in the commit view no longer rebuilds the file list, and GitLab task details are not asked for again and again
- The test build switch for the web shell is gone; the build decides

### Security & Bug Fixes
- After "Delivery unconfirmed", sending the same words again goes through as a new message instead of being stuck
- A message to a desktop-run session that ran out of time while the app was in the background now says so and puts your words back
