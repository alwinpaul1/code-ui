### Features
- Pictures Claude reads and images you paste show in the chat from your Anthropic session when the desktop can't share them; the session menu has "Check session images" to test it
- Code blocks have the Claude app's header with Copy and Expand; Expand opens the code full-height
- The composer shows the Claude app's mode chip (Accept edits, Plan, Auto) when Claude's screen states the mode

### Improvements
- Uploaded files show as cards above your message, as in the Claude app
- The model pill can show the model and effort your Anthropic session reports
- Every composer button has a larger touch target, and the effort word in the model pill is muted

### Security & Bug Fixes
- A text selection stays on its words through long scrolls and while a reply is still being written, and normal scrolling speed is back
- A Stop that fails says "Couldn't stop the session. Try again." once, and Stop works again
