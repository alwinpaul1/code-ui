### Features
- A file Claude was sent from the Claude app shows as an attachment card, and a tap opens it
- A Claude tab stays live from Anthropic while the desktop relay is down: working state, tasks and the footer keep updating

### Improvements
- The usage limit banner sits inside the composer, as in the Claude app, and every banner can be closed with its X
- On a Claude tab, the limit banner follows the limit warnings Anthropic sends for that session
- Opening a Claude session shows its newest message on the first frame, with no filling in and scrolling down; anything it missed arrives in one step
- The footer above the composer reads like the Claude app's: "thought for Ns" after thinking, a token count that counts up, and "Connecting..." on the same line as the running tasks

### Security & Bug Fixes
- A session copied from one Claude profile to another (for example from ~/.claude-work to ~/.claude) is read from the account it runs on now, so it no longer shows the other account's chat or its "Limit reached"
- A picture Claude read on a Claude tab drawn from Anthropic is placed on the right row
- A message that arrives while a long gap is being caught up is no longer dropped
