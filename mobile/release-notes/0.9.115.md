### Features
- Terminal panes are drawn by Orca's own terminal (xterm.js), the same one the Orca mobile app uses; the Ghostty engine is removed
- A turn that was cut off reads "Interrupted after N" or "Failed after N", and workspace rows and tab pills show failed, interrupted and "couldn't confirm" marks like the desktop

### Improvements
- Swiping Claude Code shows its repaints while your finger is still down
- Tapping Claude Code's screen sends the click without opening the keyboard
- Claude Code's `⏵⏵` status glyphs draw instead of boxes
- A Codex stream retry shows as one warning row that updates in place
- Every /clear, /compact, rewind and Stop press is its own action on Orca 1.4.220
- Tab pill marks read clearly on every pill, pressed or not, in light and dark
- Ports Orca 1.4.220's mobile changes: held mic buttons survive long presses, Mermaid exports survive bundling, wider terminal panes

### Security & Bug Fixes
- A reconnect or return from chat no longer blanks a terminal that was already drawn, and output arriving just before it is kept
- If Android kills the terminal in the background, it comes back on its own
- A refused chat or Stop is worded properly instead of showing an error code
- A tool result is matched to the call it names, so a failed edit is no longer blamed on a running command
- The workspace list redraws when an agent's result changes
- brace-expansion and dompurify are pinned past their security advisories
