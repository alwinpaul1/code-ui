### Features
- Photo markup looks and works like the Claude app's: the photo fills the screen, with Close, Undo and Redo, and Done along the top, and the bar steps aside while you draw
- A Claude tab linked to its Anthropic session sends your messages through Anthropic and queues them as the Claude app does, so a message goes only to that tab's session and survives the app being closed
- The context ring opens the Claude app's Usage sheet, with the session's own live context
- The Background tasks sheet lists running tasks and opens their transcripts as the Claude app does
- The empty composer on a Claude tab offers Claude Code's suggested next prompt; tap it to fill it in
- A Claude tab's / menu shows the session's own commands, and /model, /diff and /workflows open phone sheets
- The session bar gets the Claude app's Plan pill once Claude proposes a plan
- The workspace list files Claude sessions under the Claude app's states (Working, Needs input, Ready for review, Completed), with the app's Unread mark

### Improvements
- The Effort page matches the Claude app: "Recommended" on Medium, "4× or more usage" on Max, the note on what higher effort costs, and a blue check
- The working footer sits right above the composer, below any queued message, in a slightly bolder face
- "Ran N commands", "Running agent" and "Thought process" rows use the Claude app's size, weight and colours
- The question card looks like the Claude app's: a hairline edge, a bold question, a Skip button and a round send arrow, sized to fit above the keyboard
- Claude chats load behind the dancing Clawd and "Loading session…", including a workspace never opened on this phone, instead of a bare spinner or an empty list
- The working footer matches the Claude app: square dots between its parts, "thinking…" only while Claude is actually thinking, and a finished tool no longer stays on the working mark
- A running agent reads "Running agent", and a launched background agent gets the Claude app's diamond icon
- Tool runs read in the Claude app's words ("Searched code", "Ran skill /name", "Proposed plan", "Asked …"), and a proposed plan or a question gets its own row
- Thoughts in a row merge into one "Thought process" row, and narration between tool calls reads as Claude's words
- Time headers appear as in the Claude app: above the first message, on a new day, or after a pause of more than an hour
- Composer attachment chips are drawn as the Claude app draws them, with clearer TalkBack labels and larger touch targets
- A refusal shows the Claude app's card ("Switched to X", Why?, Hide, Learn more)
- A hold on Claude's words selects them in place; only your own messages open Copy / Select text
- Dictated words stay in the caption while the mic is on, and the composer's buttons fade out under the recording row
- The context ring uses the Claude app's colours: blue under 75%, yellow from 75%, red from 90%
- The Mac menu shows only the actions that apply right now, such as Sleep display or Wake display
- Every Claude session the phone starts begins in auto permission mode

### Security & Bug Fixes
- The model sheet always offers Effort, including on a Claude tab whose model is known only from Anthropic or the transcript
- A loading screen whose desktop can't be reached says so and offers Retry, and recovers on its own when the desktop comes back
- A lost Anthropic connection retries after 1, 5 and 15 minutes instead of waiting for the app to reopen, and "Connection lost…" clears once the turn has ended
- Two sends tapped together post once, and words typed while a turn ends keep their order
- A send to a session whose computer is offline says so instead of "HTTP 409"
- No red error row after Stop or for an API error; a model that needs a newer Claude Code says to update it
- Scrolling the chat no longer buzzes or selects a word under your finger
- The copy buttons on replies and code blocks show their icon again
- An agent's "Tool calls (N)" count is right for long agents
- A plan you turned down no longer opens from the Plan pill
