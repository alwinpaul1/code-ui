### Features
- A message Claude did not take goes back into the composer, with Claude's own reason shown, instead of being lost

### Improvements
- The chat shows a message as sent only once Claude on the desktop has taken it, not just when the desktop received it
- Before typing a message, the phone checks that the desktop's input box is empty, and says so instead of sending when it cannot be cleared

### Security & Bug Fixes
- A long message no longer reaches Claude twice joined by blank lines, or sits unsent in the desktop input while the chat says it was sent
- Claude's grey suggested prompt no longer stops a message from sending
- A slow desktop no longer makes a sent message look unsent, so it is not sent twice
