### Features
- A Claude Workflow shows as one card in Background tasks, with its phases, its agents and its totals when it finishes
- PR comments draw nested lists, task boxes, HTML entities, collapsible details and images as links
- Desktop dictation goes to the clipboard when no field on screen can take it

### Improvements
- A paused agent's choice shows as a question card, and a plan that asks to go ahead shows Allow and Deny
- The rich editor keeps your Markdown as written when it saves: line breaks, entities, front matter, badges, links, tables, quotes and code inside list items
- Chat replies draw line breaks, escaped marks, email links, links with brackets, maths and file globs as written
- The diff shows changes deep in long files, final-newline and line-ending changes, and long files whole
- Codex 0.158: its folder trust prompt, running turns, queued messages and model names are read correctly
- Screens that failed to load while the phone was still connecting load again by themselves once it connects
- Sizes, times and token counts round to the right unit, so 1,048,064 bytes reads "1.0 MB"

### Security & Bug Fixes
- The app no longer shows "Pair a desktop" for a moment at launch while it reads your desktops
- A desktop whose Keychain entry is locked is no longer called not found or removed
- A message queued in a named or fast-mode Claude session shows as queued, with no edit pencil where it cannot be edited
- "Allow always" appears only when the agent offers it, and a "Which…" choice is a question, not a permission request
- Unsaved project settings edits survive a reconnect and a switch between Project and Local
- A Linear comment or sub-issue posted just before you switch issues stays on its own issue
- Background tasks stay running when a stop was refused, and relaunched shells and monitors are tracked correctly
- Emoji are no longer cut in half in labels, notifications, previews and errors
- Copy says "Couldn't copy" when the clipboard refuses, instead of claiming success
- A reply full of dunder names no longer freezes the chat
