### Features
- Claude artifacts open inside Code UI: a card in the chat where Claude made one, links in Claude's replies, an Artifacts gallery from the home screen, and claude.ai artifact links from other apps
- Add an artifact to your home screen and open it straight from there
- A session with artifacts shows an artifacts button above the composer, listing only that session's artifacts and the account they belong to
- A session with more than one kind of output (a pull request, artifacts, a plan) shows one "N outputs" button, as the Claude app does

### Improvements
- Each message you queue while Claude works stays its own entry and is sent as its own turn
- Dictation corrects its words live while you speak, with the Claude app's own settings
- Scrolling a long chat stutters less: replies are no longer redrawn when a scroll starts or stops

### Security & Bug Fixes
- A message that fails to send after you leave the chat goes back into that chat's draft instead of being lost, even if the app is closed right after
- A `!` command with a picture attached is refused with a message instead of sending the picture alone
