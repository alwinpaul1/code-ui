### Features
- One sign-in in Anthropic accounts now also signs Code UI in to claude.ai, so artifacts open signed in as the account that owns them. The sign-in runs inside the app; use "Continue with email". Accounts signed in before this version need one more sign-in to open artifacts.
- Dictation in a chat uses that chat's own Anthropic account

### Improvements
- Artifacts has its own section on the home screen
- An artifact loads behind Clawd dancing, with one loader instead of two
- Your message appears and the composer clears the moment you tap Send, while Claude is idle or working
- A video, a pasted screenshot or a picture from Files shows its upload ring over its own picture, as the Claude app does

### Security & Bug Fixes
- The dictation waveform no longer shivers while you speak
- An artifact that has no claude.ai sign-in says so and opens Anthropic accounts, instead of claude.ai's empty sign-in page
- A claude.ai sign-in is kept encrypted on the phone and never reaches the app's own code; signing out of an account forgets it
