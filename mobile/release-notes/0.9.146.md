### Features
- Diffs read like the Claude app's: its colours and gutter, Expand up, down or all, "+N lines" between hunks, and comment cards with a queued-comments chip
- Hold your own message for Copy message, Select text and Undo send
- A banner says when you have hit a usage limit and when it resets
- The context sheet breaks usage into the categories /context shows

### Improvements
- A "Connecting..." or "Connection lost..." row shows in the chat while the desktop is out of reach
- Copying shows a check, and Claude's pulse shows while it works

### Security & Bug Fixes
- A dark empty rectangle no longer covers the chat when a queued message is drawn
- Copying a file link says when the copy failed
