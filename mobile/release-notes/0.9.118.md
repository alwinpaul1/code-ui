### Features
- The model picker is laid out like the Claude app: the newest Fable, Opus, Sonnet and Haiku first with a line on what each is for, then Effort, and older models behind More models
- The context ring shows on any Claude tab whose own status line prints its context figure, tabs where you typed `claude` yourself included
- In fullscreen Claude, the context ring appears when Claude warns that context is running low
- Long-press a message for Copy message and Select text, as in Orca

### Improvements
- The model and effort appear almost at once when you open a Claude chat, on every host: the phone remembers each session's model, asks the moment the chat opens, and warms it up when you open the project
- The model and effort follow a switch made with alt+p or `/effort`, read from Claude's own screen
- A hand-typed tab keeps its effort after Claude's startup banner scrolls away
- Worktree pinning, sorting and filters follow Orca's latest mobile changes, and the working rings keep turning

### Security & Bug Fixes
- Photos no longer stay in the composer after sending, and a refused message brings its photos and words back together, even if the chat reloaded meanwhile
- A message that fails to send goes back into the draft, and an expired retry no longer blocks sending that text again
- Sleep display no longer puts a Windows laptop with Modern Standby to sleep; the option is hidden there instead
- A stale model update left on the terminal no longer blanks the model pill
- On a Linux desktop, a long message typed there with accented letters or emoji is cut and matched to its chat row like on a Mac
