### Features
- Markdown you paste into your own message is drawn formatted, as in the Claude app: bold, lists, headings, inline code and code blocks with Copy and Expand
- Notifications have Reply, and "Deny with comment" to tell Claude what to do instead
- Reading settings: transcript text size, transcript and code fonts, and wrap long lines
- Pills under the chat show the pull request with its CI status, Create PR, or a "Local changes" hint, as in the Claude app
- The model picker puts older models behind "More models", as in the Claude app

### Improvements
- The permission sheet shows each mode's icon in its Claude colour; the mode chip next to + is gone, since the + sheet already has Permission
- The header menu shows whether the desktop is connected, and has Change model and Archive
- Italic text now slants: the live dictation caption and italics in messages
- Approve is not offered in a notification for questions, plan exits or destructive commands

### Security & Bug Fixes
- The dictation waveform flows across the whole take instead of restarting with each word
- The chat no longer shows through the composer while recording
- A double tap while scrolling no longer selects a stray word
- A failed Anthropic session lookup for the model pill is logged instead of failing silently
