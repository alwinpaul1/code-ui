### Features
- Tapping a run of tool calls opens a sheet listing each call by what it did, as the Claude app does: "Ran" with the command's description, "Ran agent" with the agent's task, "Used" with the tool's name; tap a row for its details
- A run whose background agent is still working reads "Running agent" until the agent reports back

### Improvements
- A Codex command and its follow-up polls show as one row in the sheet, marked failed if any poll failed
- Screen readers hear a run's failures and line counts, and a failed call's row says "Failed"

### Security & Bug Fixes
- A loop's ticks no longer show as your own messages in the chat, whether the loop runs a prompt, a slash command or Claude's built-in autonomous loop
- Ticks stay hidden after the loop's setup scrolls out of the chat or the app restarts; Claude tabs started after this update are recognised even when the phone never saw the loop set up
- A message you type that only starts with a short loop prompt's words is no longer hidden as a tick
- A loop tick no longer flashes as a bubble for a moment before the phone recognises it
