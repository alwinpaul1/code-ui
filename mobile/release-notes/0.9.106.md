### Features
- Code blocks have a header with their language and a Copy button that copies the whole block

### Improvements
- Links written as code show as code, without backticks, and bold, italic and struck words in a link show as style
- A message you send while Claude is working is placed by the time you typed it; tabs opened before this update get this once Claude restarts in them

### Security & Bug Fixes
- A message sent while Claude is working keeps its place after the chat reloads, after the phone sleeps, and while it waits in the queue box
- The same words sent in two turns show as two messages, and a long message no longer shows twice
- Several messages sent during one turn no longer stack at the end of the chat
- The chat stays on Claude's conversation when a background task starts another Claude, so the reply and tasks no longer vanish
- Background tasks stay in "N running tasks" when Claude finishes a turn while they run, and their timer no longer drops to seconds
- The "A menu is open in the terminal" notice no longer flashes after you answer a question card
- Code inside a list keeps its angle-bracket tags, ampersands and blank lines
