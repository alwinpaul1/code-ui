### Features
- Voice dictation now uses Anthropic's server-side transcription: words appear in the composer as you speak, with the first word at roughly half a second
- Sign in to Anthropic directly on the phone: Voice settings → Sign in → paste the code from the browser. No desktop changes needed.
- Efficacy latch: if the on-device recognizer produces no text within three seconds, dictation switches to Anthropic automatically

### Improvements
- Hold mode keeps listening 500 ms after you release, matching the Claude mobile app behaviour
- Final text timeout caps the wait at 2.5 seconds so the processing spinner never hangs
- Engine priority is now Anthropic (server), then on-device, then desktop local model

### Security & Bug Fixes
- The local speech model picker (Whisper, transducer downloads) is removed from Voice settings
- OAuth tokens are stored in the phone's secure store with PKCE and automatic refresh
- The voice stream client matches the Claude Code CLI protocol: periodic KeepAlive, two-timer finalize, interim promotion, and TranscriptError handling
