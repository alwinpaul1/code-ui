### Features
- Tap a photo in the composer to open it full-screen, and mark it up with the pencil before you send it
- Code files open formatted like the desktop editor: syntax colours for every language, line numbers, folding, Copy, Wrap and Save to phone
- Screen recordings over 18 MB are sent as frames the agent can read
- The model pill reads the model from the transcript on Windows hosts, where there is no status line
- Network diagnostics name the phone's VPN and say how long Android paused the app
- The update card lists what changed under Features, Improvements, and Security & Bug Fixes

### Improvements
- The ask and question cards say "Sending…" the moment you tap Submit, then "Sent" until the agent takes the answer
- The tool sheet shows a message sent to an agent, and an agent's prompt, as formatted Markdown instead of one run-on line
- The Claude star breathes while background tasks run, not only while Claude itself is working
- Light mode now reaches every screen: Files, Terminal, Browser and Voice settings, Tasks, the PR sidebar, diff review, source control, the session readers and code diffs
- The + sheet and the other sheets over the composer send the keyboard away as they open, instead of opening under it
- Photos opens straight away on Android, with no permission round trip first
- Tool rows show the Claude app's green and red "+N −N" pill, a step smaller, with the whole sentence visible
- The Background tasks sheet scrolls and drags smoothly, and the status reads "Working · N running tasks"
- Troubleshooting shows "Connected via Orca Relay" without an empty "check Tailscale" warning

### Security & Bug Fixes
- Copy under a reply copies the text as you see it, without the ** marks, backticks or ``` fences, and links keep their address
- Copying selected text from a reply copies code pills as their words, not as a "￼" box
- Submit on an ask card shows at once that the tap took, and an answered card stays up as Sent, so it no longer takes several taps
- Disabled buttons look disabled instead of looking ready to tap
- A background agent that Claude resumes counts as running again in Background tasks
- Each Markdown reply draws its code pills in a view of its own, to contain a crash seen on replies full of them
- A Claude chat no longer goes empty with a stuck "Working" when Claude starts another agent, such as Grok, in the same tab; it stays on Claude's own conversation
- Code pills, blue code and orange file paths, are no longer cropped at the bottom, and chat text has its earlier size and spacing back (0.9.101 changed both)
- Code pills in Markdown no longer float above their line below a heading
- Security: fflate 0.8.3 and rubyzip 3.7.0 (fastlane 2.240.1)
- The chat is drawn again at once after coming back from Files while scrolled up during a turn
- A message sent mid-turn from the desktop, and a "Message from" row, sit where they arrived instead of at the bottom of the chat
- MCP "Show status" and diff review "Send Notes" look at the terminal first and no longer type into an open prompt
- Diff review says why Send Notes, Stage Reviewed Files, Open in Session or a save did not go, instead of failing silently
- The background service no longer stops itself after the hourly job, and the phone keeps one relay connection per desktop
- Network diagnostics and Troubleshooting no longer contradict Home about the connection
- Prompt bubbles no longer leak into the next prompt or show twice, and tool text no longer shows as a prompt
