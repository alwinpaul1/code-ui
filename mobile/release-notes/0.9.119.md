### Features
- A reply's text is set like the Claude app: one selectable block at 15 on 22, with hanging bullets and inline code in JetBrains Mono
- A running command shows as a shimmering Running row, the same way a running agent does, and the collapsed row names the agent: Running agent: what it is doing
- The tool-run sheet matches the Claude app: a wrapping title, its row spacing, failed rows marked with a warning triangle, file names with their added and removed line counts, and Loaded tools

### Improvements
- The bubble for your own message is darker than the page in dark mode, taller and rounder
- The composer's + and mic sit in filled circles, and send is an accent circle that dims until there is something to send
- The bottom of the chat fades into the page above the composer, and the newest line and the jump button stay clear of it
- Copy and the up arrow appear once at the end of each reply, copy the whole reply, and jump to its start
- Holding a message selects text across paragraphs again and copies it as plain text, as it did in 0.9.116
- The context ring and the model and effort are read from your own status line even when no turn row is on screen

### Security & Bug Fixes
- A message no longer shows as not sent when you switch away from the app right after sending and come back; if it truly did not leave the phone, it says so and puts your words back
- TalkBack lists and opens the links in a reply again
- When the desktop refuses to share a picture the agent read, the phone's log names which sharing rule refused it
