### Features
- Sending a message that starts with `!` asks before it runs as a shell command on the desktop, and the command then shows once in chat

### Improvements
- A send waits for the connection to come back, and for a briefly unavailable desktop screen, instead of failing at once
- Red confirm buttons are easier to read in dark mode

### Security & Bug Fixes
- A message is not typed when the desktop cannot show its screen; the send stops and keeps your draft
- A message is never typed into a shell from a Codex tab: when Codex's input box is not on the desktop screen, the send stops and keeps your draft
- Editing a queued message no longer runs it as a shell command when it starts with `!`
- A shell command that cannot be confirmed asks you to check the terminal instead of inviting a retry that would run it twice
