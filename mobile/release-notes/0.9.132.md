### Features
- When the desktop won't share a picture an agent read, tap its placeholder and "Ask Claude to share it": one message asks for the file's path, and the picture appears once the reply names it
- A screenshot that was never saved as a file shows as a "Screenshot" chip that says so

### Improvements
- The effort sheet shows the effort Claude actually reports; a new pick reads "High…" until Claude confirms it, and says once if Claude didn't take it
- Tapping an answer on a question card only selects it; nothing is sent until you tap Submit
- Picture placeholders keep space between them, show one slot per file, and a tap explains why the picture isn't there

### Security & Bug Fixes
- A tab running an agent Code UI can't chat with, such as Antigravity, opens straight in the terminal instead of under a chat box
