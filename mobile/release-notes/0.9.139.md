### Improvements
- Tapping the mic while signed out of Anthropic says so and opens Voice settings, instead of trying and failing
- The host menu shows the Mac or PC controls at once when opened again, instead of hiding them behind "Checking the Mac…"
- Send now shows "Sending…" while it works
- The text cursor follows the app's light or dark theme in every text field

### Security & Bug Fixes
- Voice dictation uses only the Anthropic sign-in made on the phone; the app no longer reads Claude Code's credential from the desktop
- Dictation no longer fails with "unstructured server error" after signing in on the phone, and a server error now says what the server sent
- Done after pasting the sign-in code, and other buttons beside a text field, work on the first tap
- Send now on a queued message works on the first tap
- The terminal's text field keeps the keyboard after a tap or scroll on the terminal, so its cursor shows
- A terminal opened again paints at phone width at once, instead of flashing at desktop width first
- Selected text in the chat and the terminal stays selected while scrolling
- A host check that never answers keeps the controls shown instead of hiding them
