### Features
- Claude chats come from Anthropic: a matched session draws exactly what the Claude app shows, live, with older history as you scroll up. Sign in under Settings, Anthropic accounts
- A new Anthropic accounts screen in Settings: each account with its own Sign out, Add another account, and Sign out of all accounts
- Holding a message opens the Claude app's menu with Copy and Select text; scrolling never opens it
- Pills under the chat show the pull request, Merged, CI and Diff from Anthropic, in the Claude app's colours
- New Claude sessions start with Remote Control on (Settings, Chat UI)

### Improvements
- The working line is the Claude app's: its spinner, a cycling verb and "N running tasks"
- The context ring and usage limits are this session's and this account's, work and personal kept apart
- A tool without its own view opens a detail sheet laid out like the Claude app's
- The model pill shows the model and effort for sessions started by hand, from either account

### Security & Bug Fixes
- Editing a queued message no longer shows it twice
- A tab finds its session faster and no longer settles on an older one from before a resume
- Copying a message gives the words as drawn
