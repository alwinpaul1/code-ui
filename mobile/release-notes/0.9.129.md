### Features
- Pictures an agent reads or sends now show in the chat as thumbnails, where the Claude app puts them; tap one to open it full screen, download it, or mark it up
- Markup draws smooth strokes, saves photos as JPEG, and adds the drawing to your message as an attachment
- Stop now sits in the send button's place while Claude works, and tapping a queued message moves it back into the box to edit
- Running steps read "Running", "Reading" or "Running agent: <task>" with the Claude app's shimmer, and stop as soon as the work ends
- Copy sits under a reply's last words, above a shell or agent that is still running
- Thinking shows as a "Thought process" row, errors as error rows, and a finished turn that changed files gets an edits card with Review
- Plan approval reads "Approve & auto mode", "Approve Plan" and "Suggest Edits"; question cards count "1 of N"
- The mode sheet lists Manual, Accept edits, Plan and Auto; the model sheet puts Effort under the main models
- Task and diff pills above the box, with a todo card behind the task pill
- The file viewer numbers lines and can load the whole file; a finished shell can show its output; an agent's sheet lists its tool calls
- The header menu adds Copy branch, Background tasks, Rename session and Copy session ID
- A new black launcher icon; the splash and in-app logo are black in light mode and white in dark mode

### Improvements
- Each attached photo is ready as soon as its own upload lands, up to 20 per message, and a failed one shows Upload failed with Retry
- Closing a terminal tab is instant; it only comes back if the desktop refuses
- A message sent while Claude is working shows where you sent it, and one typed on the desktop shows where Claude read it
- Selecting text in a reply shows only Copy and Select all, in the app's accent colour
- A sent message is dimmed only until the desktop takes it
- The scroll-to-latest arrow sits in the middle and only shows when there is more below
- The Background tasks sheet has no Stop buttons and names each agent by its task
- Dark-mode text is whiter and easier to read
- The model name no longer repeats in the header; it stays in the message box
- "Thought for Ns" no longer shows beside Working, and a subagent's hand-back draws no row

### Security & Bug Fixes
- A message refused because Claude's input box wasn't on screen now waits and sends itself when it is back; other refusals keep your text with Retry
- A photo message is no longer shown as sent when it never reached Claude
- A send that fails partway keeps its photos, words and bubble together
- While dictating, the text stays inside the box and the cursor stays after your words
- The update spinner sits in the middle of its dialog
