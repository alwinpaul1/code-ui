### Improvements
- Voice dictation is always on: the Enable Voice Dictation switch is gone from Voice settings, and the dictation mode can always be changed

### Security & Bug Fixes
- Sign in to Anthropic opens a page that shows the code to paste back, instead of "Invalid OAuth request: Missing state parameter"
- A pasted code missing its part after # or from an older sign-in is refused with a message saying so
- The pencil on a photo opens the markup editor on the first tap, instead of sometimes showing nothing until the photo was opened again
